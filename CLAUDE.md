# CLAUDE.md — AD Flower Stall website

Client project (a family flower stall, not a Zyllo Tech product). Static HTML/CSS/JS, no build step, no framework.
Repo: https://github.com/nameissankar445-ctrl/AD-Flower-Stall (branch `main`). This folder is on a cloud-synced drive — do **not** run `git init` here (sync corruption risk, see workspace CLAUDE.md). Do git work in a separate folder and copy files across.

- Ideal: replace with the owner's own stall photos when supplied (phone photos are fine).
- Design: calm and not too colourful — flat colours, no gradients, no falling petals/glow effects.
